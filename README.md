# Réplica de Hoja de Vida de Noé Reyes

Sitio estático basado en https://noereyes10.github.io/noe22025/index.html.

La página principal, la página de educación y la fotografía se conservan tal como aparecen en el repositorio público https://github.com/noereyes10/noe22025. Las páginas de experiencia laboral y habilidades completan los enlaces ausentes usando la información de la página principal.

## Abrir localmente

Abrir `index.html` en un navegador, o ejecutar `npm start` con Node.js y visitar http://127.0.0.1:5173. No requiere instalar dependencias.
